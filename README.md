# Automatic Power BI Dashboard Generator
100% Free, no paid tools, no subscriptions required.

## 🚀 How to use:
1.  Double click `run.bat` (Windows) or run `python main.py`
2.  Click Browse and select your Excel / CSV data file
3.  Choose your favorite theme from the dropdown
4.  Click Generate Dashboard
5.  The program will automatically:
    - Clean your data (remove duplicates, fix missing values)
    - Detect column types automatically (supports Arabic and English)
    - Calculate all KPIs automatically
    - Generate Power BI custom theme file
    - Generate DAX measures for KPIs
    - Create interactive HTML dashboard preview you can view in browser
    - Create step-by-step setup guide
    - Open the output folder automatically

## 🎨 Available Themes:
- Luxury Gold (dark premium executive)
- FitPro Red (sports/gym)
- Wallet Teal (light finance)
- Dark Purple Analytics (dark data dashboard)
- Trading Neon Green (crypto/stocks)
- Rexora Light Modern (light CRM/sales)
- Control Dark Blue (admin/management)

## 📦 Output files:
- `cleaned_data.xlsx`: Your fully cleaned dataset
- `powerbi_theme.json`: Power BI compatible theme file
- `dax_measures.txt`: Copy-paste DAX KPIs for Power BI
- `dashboard_preview.html`: Interactive web preview
- `Setup_Guide.txt`: Step by step import instructions for Power BI

You don't need to do any manual work - just select your file and theme, everything else is automatic.
